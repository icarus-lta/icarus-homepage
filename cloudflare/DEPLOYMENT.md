## 메일 인증 상태

가비아의 DKIM 값은 사용자가 제공한 공개키와 정확히 일치한다. CNAME `rsend`/`send`, `_dmarc`도 Google 및 Cloudflare 공개 DNS에서 조회된다. 다음 MX `aspmx.daum.net` 우선순위 10, `alt.aspmx.daum.net` 우선순위 20 유지. 기존 웹 `www` CNAME과 네임서버는 변경하지 않았다.

Resend 인증은 Verified로 완료되었다. 직접 발송 테스트가 HTTP 200으로 접수되었고, 실제 브라우저 문의/지원서 재제출도 각각 완료 화면까지 확인했다. 지원서는 실제 브라우저에서 10MiB PDF 두 개를 첨부했다. 사용자가 다음 스마트워크 받은메일함에서 직접 테스트·문의·채용 지원서 세 메일 도착 및 채용 메일의 첨부 표시를 확인했다. `Enable Receiving`은 꺼두고 다음 스마트워크를 수신 서버로 유지한다.

운영 만료 시각까지 실제로 24시간 기다린 검증은 아직 하지 않았다. 저장소 키 자체의 절대 만료와 서버 서명 만료는 설정/테스트되어 있다. Cron은 개인정보 제거 및 만료 기록 정리를 하나의 D1 batch로 처리하며 파일 삭제는 KV의 절대 만료 기능에 맡긴다.

API 전용 합성 테스트 접수 4건의 개인정보와 임시 파일 7개는 정리했다. 실제 브라우저로 발송한 문의/지원서는 정상 보존 기간에 따라 만료된다. 최종 배포 버전(2026-09-30): `2d3d3139-c546-477f-82e6-1e656488e0c9`.
